MASTER PROMPT — EMPLOYEE MANAGEMENT SYSTEM
1. PROJECT TITLE
Build a complete full-stack web application named:
“Employee Management System”
This project is an academic CRUD-based web application developed according to the provided Standard Operating Procedure (SOP) — Complete CRUD-Based Web Application Development.
The application must demonstrate:
    • Create
    • Read
    • Update
    • Delete
    • Database integration
    • REST API
    • Frontend-backend integration
    • Input validation
    • Error handling
    • Search and filtering
    • Authentication
    • Role-based access
    • Testing
    • Documentation
    • Responsive UI
Do NOT build only a frontend design or static prototype.
The application must be genuinely functional.

2. MAIN OBJECTIVE
Develop a modern Employee Management System that allows an organization to digitally manage employee information.
The system should allow authorized users to:
    • Add employees
    • View employees
    • Edit employees
    • Delete employees
    • Search employees
    • Filter employees
    • View employee details
    • Manage departments
    • Manage job positions
    • Manage employee attendance
    • Manage leave requests
    • Manage salary/payroll information
    • View reports
    • Manage notifications
The application must store all important information in a real database.
